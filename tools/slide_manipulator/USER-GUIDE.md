# EasyPath Slide Manipulator 0.3.1

Choose local slides in **Input**. In **Basal layer** or an added frame, select a source plane and use **Add whole slide** or **Open**. In the opened source, Shift+Z records the moving pointer, Shift+S saves a mapping crop, Shift+A steps back, Shift+R clears a draft and Shift+D subtracts a draft from overlapping crops. Right-click a saved crop to remove it and its linked placements in the current frame. Choose **Add segmented region** to place a saved crop. Source slide files and their annotation files are never edited.

The frame tab preview is read-only. In **Open manipulation**, drag a placement to move it, drag its center dot around the pivot to rotate, right-drag horizontally to resize, or double-click to choose **Flip horizontally** or **Flip vertically**. Drag the background to pan, scroll to zoom, or choose **Auto fit**. Added frames overlay the locked basal frame; the two opacity sliders (defaults 0.3 and 0.5) affect the editor only. Later placements appear above earlier placements within each exported plane.

Frame names appear on their tabs. **Add frame** inserts after the current frame. Switch left/right or delete an added frame; the basal layer always stays first. Optional distance is saved in millimeters as mapping metadata and is not treated as measured DICOM focal spacing.

In **Output**, the left column has one source: **Merged slide**, which contains the basal layer and all added frames. Open it to draw output crops on any frame. Use the frame selector or Shift+Page Up/Down to inspect another section. Add the whole slide or a saved region, then choose **Open manipulation** to arrange the placements. Each move, rotation or mirror applies to all frames. **Generate slide** writes that arrangement. When upstream edits change the merged bounds, explicitly reset the output layout before selecting new regions; this does not reset basal or frame placements.

Save a new **.epmap** project to keep the original slide paths and placements. Load requires the same local source files. Preserve companions such as the MRXS data folder. Save and Generate refuse to overwrite existing paths. The desktop project is local, not a server workspace. It does not copy or route source annotation sidecars.

EP defaults to 8 bits, maximum 5% error, JPEG XL distance 4; 8 bits/0% is lossless. TIFF is lossless. EP and TIFF encode the basal frame first and additional frames in displayed order. Uncovered pixels are white. Different scanners may have different native pixel spacing; use right-drag to scale a placement. Earlier projects open with their original whole-stack output; new projects save output crops and placements in a version 3 document.

DICOM writes a new directory ending in .dcm containing WSI instances. It requires a separate verified facts JSON: top-level keys mpp_x and mpp_y (positive output micrometres per pixel) and sections (one acquisition/specimen object per frame in order). Each section requires acquisition_datetime with timezone, focus_method, source_was_lossy and its actual compression_history if lossy, contains_patient_text, imaged_depth_um, origin_x_mm, origin_y_mm, rotation_degrees, slide_identifier and specimen_identifier. Patient details must agree across sections. Use only verified values; do not treat stains or separate sections as scanner focal positions. Mixed-source montages and several planes of the same source cannot be exported as distinct DICOM specimens; use EP or TIFF instead.

Supported inputs include recognized scanner SVS, NDPI, MRXS, BIF, SCN, supported pyramidal or focal TIFF and EP. iSyntax requires a permitted Hospital Research reader. DICOM is an output format in this first version. An embedded profile is respected. Assume sRGB is checked by default for sources without a profile. Uncheck it when that assumption is inappropriate. Embedded profiles take precedence. General builds exclude proprietary runtimes. Hospital Research builds are for authorized nonprofit research use only.
